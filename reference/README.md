# Python reference

Copies of the Anki-era `satori_decks.py` / `satori_gloss.py` tools and tests used as a behavioral specification for:

- Satori CSV field names
- sentence normalization / dedupe intent
- Cure Dolly chunk & role heuristics
- worksheet text structure
- ichi.moe URL shape

The web app does **not** run these files. Algorithms were selectively ported to TypeScript under `src/lib/`.
